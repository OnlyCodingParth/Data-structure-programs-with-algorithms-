# Graph Representation - Complete Theory

## 1. Introduction

A **Graph** is a non-linear data structure used to represent relationships or connections between objects.

A graph consists mainly of:

- Vertices
- Edges

A vertex represents an object.

An edge represents a connection between two vertices.

For example, in a social network:

- People can be represented as vertices.
- Friendships can be represented as edges.
